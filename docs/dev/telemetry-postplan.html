Dual-Sink Ingestion Pipeline & Privacy Safeguards

UI / Engine / Lifecycle Action → TelemetryService.TrackAsync() → Channel<TelemetryEvent> (Bounded: 500, DropOldest) → TelemetrySanitizer (DAG Cycle-Safe Recursion) → PostHog Analytics Sink (us.i.posthog.com) & Sentry Crash Sink
GDPR & Anonymity Guarantees

Absolute client IP masking ($ip: null, ip: false), zero hardware fingerprinting, and zero personal data collection. Only anonymous installation GUIDs are used.

Local Path & Secret Scrubbing

Local filesystem paths (C:\Users\..., /home/...) are stripped to basenames. Query parameters, tokens, and authorization headers are proactively scrubbed.

Crash Forensics (Sentry + PostHog)

Unhandled crashes emit structured app_unhandled_crash events to PostHog and stack traces to Sentry. Stack frames are sanitized to hide private file paths.

Bounded Channel & Backpressure

In-memory Channel<TelemetryEvent> bounded to 500 entries with BoundedChannelFullMode.DropOldest guarantees zero UI stutter or memory leaks.
