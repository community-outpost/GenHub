Autonomous Upstream Releases, ContentBundles & Featured UI

Complete technical specification for autonomous upstream tracking, user-side variant swapping in ContentBundles, Publisher Studio authoring UI, and golden featured priority.

1. Unified Architecture: Dynamic Upstreams vs Static Releases

The catalog ecosystem cleanly bifurcates into two types of content items:

Dynamic Upstream Items Zero Releases in JSON

Items tracking fast-moving external codebases: TheSuperHackers (GitHub weekly builds), GeneralsOnline (CDN ladder releases), or Community Outpost (GenPatcher).

  • NO releases array authored in catalog.json: The publisher never manually types version numbers or download URLs.
  • Autonomously Ingested: When GenHub launches, it calls the built-in discoverer (e.g. GeneralsOnlineDiscoverer). If upstream has a new release, GenHub creates the physical release locally and writes the manifest to disk.
  • Publisher-Independent: If the catalog author is inactive or absent, the catalog never dies. End-users always get the latest releases.
Static Addons & Overlays Explicit Releases in JSON

Independent community mods and assets: L3M ControlBar, Eliorata Improved Menus, Leikeze Hotkeys, and custom Map Packs.

  • Explicit releases: [...] required: Authored in Publisher Studio with concrete download URLs, hashes, and version numbers.
  • Multi-Variant Artifacts: A single release contains multiple artifacts tagged with variant axes (e.g. 1080p, 1440p, 4K).
  • Stable Baseline: These assets don't change every week; they remain pinned or versioned until updated by their author.

How Variant Swapping Operates Internally

In GenHub, ContentCardView.axaml binds to ContentGridItemViewModel and child BundleComponentViewModel:

  • Reactive Selection: When the user changes SelectedOption on a child component's VariantAxisGroup (e.g. switching ControlBar from 1080p to 4K), the ViewModel instantly swaps the target artifact in the dependency graph.
  • Dynamic CAS Hash Resolution: When the user clicks "Install Complete Suite", GenHub resolves the exact artifact SHA256 checksums matching the user's variant choices.
  • Launch Profile Generation: The resulting profile is configured with the selected variant flags (e.g. ScreenResolution=3840x2160, Language=en).
